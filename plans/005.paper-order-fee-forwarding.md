# 005 — paper order's fee never reaches the outgoing ExecutionReport

Plan for [`specs/005.paper-order-fee-forwarding.md`](../specs/005.paper-order-fee-forwarding.md).

## Solution

- `ExecutionReport` (`src/userStream.ts:259-281`) gains `feeSide?: 'base' | 'quote'`,
  alongside the existing `feePaid`/`feeAsset`/`feeBreakdown`/`feePaidUsd`.
- `PaperOrderMessage` (`:430-444`) gains `feePaid?: string` and
  `feeSide?: 'base' | 'quote'`.
- `preparePaperOrderMsg` (`:4194-...`) copies both, present-if-present,
  the same pattern the real-venue normalizers use for their own fee
  fields (this repo's spec 003 / `venueFeeForwarding.test.ts`).

This is the root cause spec 005's Assumption names — `msg` simply had
nowhere to carry the fields and nothing read them; there is no other
transformation on this path to get wrong.

## Why no extraction

JIT tier **0**. Two type field additions plus two spread lines
following an established pattern in the same function — nothing here
mixes decision logic with I/O.

## Blast radius

1. **Other call sites.** `preparePaperOrderMsg` has one call site
   (`:3612`, inside the paper `cbOrder` callback) — grepped, confirmed.
   `PaperOrderMessage` is used only by that callback and
   `paperTradingWS.ts`'s type import — the bridge forwards whatever
   shape it's given, no change needed there.
2. **`core/` submodule.** This file is `websocket-connector-sh`,
   shared/deployed platform-wide — parent pointer bump needed at ship
   time, alongside paper-trading's own pointer bump (see paper-trading
   plan 003, build order).
3. **Contracts this repo owns** (`CLAUDE.md` "socket.io bridge to
   paper-trading" + the Redis-published `ExecutionReport`/
   `UserDataStreamEvent` main-app consumes): both gain an optional
   field, nothing renamed or removed — non-breaking for every existing
   consumer, including main-app before it's updated to read `feeSide`
   (app spec, separate).
4. **Other tests.** `venueFeeForwarding.test.ts` (this repo's spec 003)
   exercises the five real-venue normalizers — untouched, must stay
   green.
